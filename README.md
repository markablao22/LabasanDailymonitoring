# Labasan Daily Monitoring

Installable, responsive Daily Operations Monitoring PWA for desktop and mobile.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.
4. Open the published HTTPS URL to install on desktop or Android.

## App notes
- Responsive layout for desktop, tablet, and mobile.
- Offline app shell after first successful load.
- Records are stored locally in each browser/device; they do not automatically sync.
- This is a PWA, not a native APK or Windows EXE.
